# nabhan lyric.

Personal site: a boot screen, a 3D PSP playing my favourite song, my projects, about, contact.
Plain HTML, CSS and JS with three.js from a CDN. No build step: serve the folder.

    python3 -m http.server 8000

- `js/data.js`: what the PSP plays (now-playing slot).
- Projects live in `index.html` (`#projects`), images in `assets/projects/`.
